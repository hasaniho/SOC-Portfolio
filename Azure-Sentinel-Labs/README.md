# Azure Sentinel Labs

Hands-on Microsoft Sentinel labs demonstrating log ingestion, SIEM configuration, KQL analysis, and security event investigation in Azure.

## Labs Included
- **Lab 01 – Windows Security Events Ingestion & Analysis**
  - Connected an Azure Windows VM to a Log Analytics Workspace
  - Ingested Windows SecurityEvent logs into Microsoft Sentinel
  - Verified data flow and explored logs using KQL

Each lab folder contains a dedicated README with detailed steps, observations, and screenshots.
